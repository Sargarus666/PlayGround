# VK Mini

Минимальный неофициальный клиент ВКонтакте для Android: лента, сообщения, музыка и профиль.
Material You (динамические цвета Android 12+, на Android 13 выглядит нативно), компактная вёрстка,
без рекламы, аналитики и рекомендаций.

> Это не мод и не перепаковка VK / VK Sova. Приложение написано с нуля и работает через официальный
> VK API. Внутри только собственный код, поэтому «вырезать мусор» не пришлось — его здесь нет.

## Что внутри

- **Лента** — посты, фото, лайки/комментарии/репосты, догрузка, pull-to-refresh.
- **Сообщения** — диалоги и беседы, непрочитанные, отправка сообщений, отметка о прочтении.
- **Музыка** — `audio.get` из аккаунта, встроенный плеер. VK отдаёт аудио не всем токенам,
  поэтому при отказе показывается понятное объяснение, а не пустой экран.
- **Профиль** — аватар, статус, город, счётчики, сведения о приложении, выход.
- **Демо-режим** — посмотреть все экраны без токена.

Чего нет: рекламы, трекеров, рекомендаций, сторис, клипов, мини-приложений, лишних разрешений.
Единственное разрешение — `INTERNET`.

## Установка

Готовый APK: [`apks/vk-mini-0.1.apk`](apks/vk-mini-0.1.apk) (Android 8.0+, ~7 МБ).

1. Скачай APK на телефон и разреши установку из этого источника.
2. Открой приложение и вставь `access_token` (или нажми «Посмотреть демо»).

Токен хранится только в приватных настройках приложения и уходит исключительно на `api.vk.com`.

### Права токена

`friends`, `wall`, `messages`, `photos`, `audio`. Токен удобно получить через OAuth implicit-флоу
своего Standalone-приложения в VK ID: после редиректа `access_token` будет в URL.
Музыка работает только если приложению/токену доступен `audio.get` — это ограничение VK, не клиента.

## Сборка

Нужны JDK 17 и Android SDK 35.

```bash
./gradlew :app:assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

Release подписывается демо-ключом из `keystore/vk-mini.jks` (пароль — в `gradle.properties`),
чтобы новые версии ставились поверх старых. Для публикации замени ключ на свой.

## Структура

```
app/src/main/java/com/playground/vkmini/
  MainActivity.kt          вход, edge-to-edge
  AppViewModel.kt          сессия, загрузка данных, плеер
  data/                    VK API, модели, демо-данные, хранение токена
  ui/                      тема Material You, экраны, компактные компоненты
```

## Ограничения

- Неофициальный клиент, не связан с VK. Товарные знаки принадлежат их владельцам.
- VK может изменить API; музыка и newsfeed особенно зависят от прав токена.
- Нет push-уведомлений: сообщения обновляются кнопкой и при открытии экрана.
